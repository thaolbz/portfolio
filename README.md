# Portfolio - Matheus

Portfolio interativo com estetica de terminal Linux.

## Como usar

Abra o arquivo `portfolio-matheus/index.html` em qualquer navegador.

## Comandos

| Comando | Descricao |
|---------|-----------|
| `passeio` | Apresentacao guiada automatica |
| `ajuda` | Lista todos os comandos |
| `quem` | Apresentacao pessoal |
| `sobre` | Historia detalhada |
| `habilidades` | Tabela de hard skills |
| `pessoais` | Tabela de soft skills |
| `interesses` | Areas de interesse |
| `log` | Trajetoria profissional |
| `projetos` | Projetos em desenvolvimento |
| `musica` | Toca/pausa musica |
| `contato` | Informacoes de contato |

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
